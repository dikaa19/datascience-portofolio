# 📊 Data Science Portfolio

Repository ini berisi portofolio proyek Data Science, Machine Learning, dan AI:

## 📁 Struktur Repository

```text
datascience-portofolio/
├── 📁 modelling/       # Kumpulan Proyek Machine Learning & Data Analytics (Jupyter Notebooks)
└── 📁 mcp_practice/   # Implementasi Model Context Protocol (MCP) Server & Integrasi Gemini AI
```

---

### 1. 📁 `modelling/`
Berisi kumpulan eksperimen dan proyek Machine Learning / Data Science:
- **`airplane_passenger_satisfaction.ipynb`**: Analisis dan pemodelan kepuasan penumpang pesawat.
- **`garment_worker_productivity.ipynb`**: Prediksi produktivitas pekerja garmen.
- **`rice_clasification.ipynb`**: Klasifikasi jenis beras.
- **`[Clustering]_Submision_Akhir_BMLP_Khafidz_Putra_Mahardika.ipynb`**: Pemodelan clustering data.

---

### 2. 📁 `mcp_practice/`
Berisi proyek implementasi **Model Context Protocol (MCP)** menggunakan **FastMCP** yang diintegrasikan dengan **Google Gemini API**:
- **`server.py`**: MCP Server dengan tool analisis data SBN berbasis Pandas.
- **`client.py`**: MCP Client untuk pengujian otomatis.
- **`gemini_chat.py`**: Asisten AI interaktif berbasis Gemini yang memanggil MCP Tools.
- 📖 **[Lihat Dokumentasi Lengkap MCP Practice](mcp_practice/README.md)**
